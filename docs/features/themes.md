# Themes

Two themes ship with the app:

- **Catppuccin Mocha** — dark
- **Catppuccin Latte** — light

Pick one from View ▸ Theme, which also offers **follow the system**, so the
app flips with the OS appearance setting. The choice is persisted in
`config.json`.

The theme covers the editor's syntax highlighting as well as the chrome, so
the [SQL editor](sql-editor.md), the results table and the
[query-plan flame graph](query-plan.md) stay consistent in either flavour.
